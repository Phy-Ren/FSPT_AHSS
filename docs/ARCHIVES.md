# Current references and historical archives

Use the [formula guide](FORMULA_GUIDE.md) for the current mathematical
definitions and the [computed-example catalogue](../results/computed_examples/README.md)
for the consolidated completed results.

Earlier releases retain their original result bytes, source versions,
documentation and manifests. A scope statement inside an earlier archive
describes that release's implementation, rather than the current engine.

| Collection | Scope of the retained release | Current entry point |
| --- | --- | --- |
| [Crystalline group tables](../results/group_tables/README.md) | Earlier 524 crystalline calculations with their source-specific layer/group tables | [Consolidated catalogue](../results/computed_examples/README.md) |
| [Finite examples](../results/finite_examples/README.md) | Earlier 16 full 3+1D groups and 53 graded 4+1D classifications; historical formula-availability statements apply to that release | [Current finite families](../results/computed_examples/tables/families.md) |
| [Complete-formula release](../results/complete_formulas/README.md) | 832 retained numerical records, including production calculations and controls | [All completed calculations](../results/computed_examples/README.md) |
| [October 2 supplement](../results/complete_formulas_20261002_supplement/README.md) | Five accepted finite calculations | Included once in the consolidated catalogue |
| [Cochain/geometric controls](../results/finite_examples/calibrations/README.md) | Separate local and geometric calibration calculations | Retained as controls with their original scope |
| [Resolution certificates](../results/resolution_certificates/README.md) | Exact boundaries, contractions and transport for optional finite resolutions | Applicable reproduction strategies are retained per calculation |

All 69 dimension/background rows in the earlier finite-example archive are
accounted for in the consolidated completed catalogue. Their historical
associated-graded results are not substituted for the current full stacking
groups. Formula availability and coordinate conventions for the current
3+1D/4+1D implementation are stated in the canonical formula guide.

Current reader tables merge equivalent backgrounds and repeated runs;
all original numerical records remain in their source archives. The
[unique index](../results/computed_examples/unique_examples.json) records
this distinction: 1,190 reader examples account for 1,234 retained calculations.
Generated tables from earlier organizations are replaced by the current
views, rather than retained as competing result lists.

The archive manifests remain useful for checking their original contents.
`ORGANIZATION_MANIFEST.json` records the separate documentation/catalogue
overlay, rather than rewriting those earlier manifests.

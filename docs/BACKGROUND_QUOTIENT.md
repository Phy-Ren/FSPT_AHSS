# The unitary H0 p+ip incoming quotient

`gap/background_quotient.g` computes the quotient of the complete marked
Majorana / complex-fermion / bosonic stacking group by the actual H0 p+ip
boundary. It uses the physical extension cocycle supplied by the caller. It
does not identify this boundary with a separate quotient of each graded layer.

For unitary sign, `AFSBackgroundIncomingState(ctx)` supplies the flat state
`X = (omega, 0, F(omega)/16)`. The independently checked identities in
`gap/pip_incoming_background.g` show that `16 X = 0`. The actual order can be
smaller; the quotient module measures it from the complete relation matrix.

## Preserving the actual incoming state

The incoming Majorana class is expressed in the final pre-H0 Majorana basis.
When nonzero, choose a nonzero coordinate and replace that marked generator
by the complete state X. The basis transformation is the identity with that
row replaced by the coordinate vector, and has determinant one. All other
marked lifts are retained, and all power relations are measured again. X is
then literally a marked generator, so its coordinate row is a unit vector.
This avoids silently identifying cohomologous Majorana cochains without the
required nonclosed Majorana gauge.

For a literally zero Majorana cochain, the ordinary complete CF/phase
reduction finds the incoming coordinates. A nonzero Majorana callback whose
cohomology class vanishes is deliberately unresolved in this wrapper: the
caller must first supply the gauge. The production background installer has
a separate exact-background reduction for this case.

## Integer quotient and the new graded groups

Let the marked group be `H = Z^m / row_Z(R)`, with generator layers 0, 1, 2
for bosonic, CF, MC. Append the actual incoming coordinate row x to R and
compute the Smith form. This presents `H / <X>`, including every nontrivial
power of X in a lower layer.

To compute its filtration, let `L_i` be the coordinate lattice generated by
marked generators of layer at most i. For each i, take the columns of R above
layer i and compute `U R_high V = S`. The zero rows of S identify the last
rows of U as a saturated integer basis of the left kernel. Their combinations
of R generate `row_Z(R) intersect L_i`. Restricting those rows to `L_i`
presents the filtered subgroup; projecting further to coordinates of exactly
layer i presents its graded quotient. This also works for redundant marked
generators and for free factors.

The export retains the original complete group, its cochain witnesses, the
actual incoming state, coordinate row, measured order, basis change, all
Smith transformations and all integer intersection certificates. The
post-quotient marked generators may be redundant. Their old `quotientOrder`
labels are not the new graded orders: the new classification is explicitly
stored in `backgroundQuotient.graded` and the new filtration certificate.

## API

- `AFSBackgroundQuotientPresentation(lower, x, certificate)` is the pure
  integer core. An optional `certificate.orderDivides` is checked against the
  measured order.
- `AFSBackgroundQuotient(C, X, certificate)` constructs and remeasures the
  marked group using actual cochains. It does not mutate C's summary.
- `AFSBackgroundQuotientExport(C, result)` returns JSON-compatible witnesses
  and presentations. The caller installs the new graded classification.

`tests/test_background_quotient.g` covers nonsplit and split finite groups,
odd torsion, a free group, a trivial boundary and the empty group. It checks
the retained integer intersection witnesses and independently enumerates all
eight possible incoming elements of Z/8. Actual full affine-group controls
are in `tests/test_background_quotient_cochains.g`; run evidence is stored in
`docs/validation_runs/background_quotient.json`.

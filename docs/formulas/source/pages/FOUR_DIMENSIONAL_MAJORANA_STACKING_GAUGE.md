The sum contains exactly **419 physical-face products**, listed in the

Every row is one product of the explicitly named physical cochains on
explicit faces of (01234). Every binary coefficient is one. The remaining
bracket contains two integer cup terms. No field on another physical
simplex or unspecified primitive is needed to use this gauge.

The inverse change adds the displayed coboundary. The obstruction function
is unchanged because the twisted differential squares to zero. The output
phase therefore represents the same bosonic cohomology class. The formula
and this gauge hold for open Majorana cochains; imposing that their
differentials vanish is unnecessary.

All integer cups, canonical binary lifts, and Bocksteins use the conventions
in the main formula guide. The sum inside an open Bockstein is a binary
sum before its canonical lift.

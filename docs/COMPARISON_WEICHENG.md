## What the supplied materials actually contain

The boss's separate `space_group_230_layers.pdf` reports four filtration
quotients for all 230 infinite affine space groups. Its convention agrees
with this calculation: physical spin-half fermions, effective omega=0,
orientation character det, and retained weak/atomic layers. It explicitly
does not determine all stacking extensions. The separate PDF comparison
matches all 920 layer entries; see the boss comparison report.

The supplied 347,645-byte archive is truncated; 171 complete files were
recovered in `/tmp/AllFSPT-inspect-boss`. Its README names final
`space_group_layers.json/csv`, but those files are absent from the recovered
part. The recovered `hap_all230_e2.json` and `hap_bosonic_all230.json` are
intermediate ordinary-cohomology tables, explicitly labeled E2 only, with
229 and 214 completed entries respectively. They must not be treated as
final classifications or stacking results.
The available raw inputs also agree independently: all 687 recorded
H1/H2/H3(F2) dimensions across the 229 completed rows match, as do all
230 signed H1 free/torsion pairs. The archived H4(U1_s) table is not compared
to final bosonic quotients, since they are different stages of the calculation.

A useful separate reference is recovered
`output/space_group_230/draft_table.json`: a transcription of the historical
20 September manuscript, containing 230 layer rows and 204 nonblank
full-stacking entries. The recovered file labels these as transcribed claims,
without an independent calculation. All four same-layer disagreements below
were subsequently confirmed in both the supplied original manuscript and
completed original SptSet logs. These remain historical results, rather than
outputs of the boss's new calculation. Its SHA256 is
`fcfba0ffbd4f1219721923059556efbdad59f64eb7e1f9caeec89c545d563d0f`.

The collaborator repository is pinned to
[`c2961a2d6ee9465a7b634a31b6c095e607972966`](https://github.com/Weicheng-Ye/fermionAHSS/tree/c2961a2d6ee9465a7b634a31b6c095e607972966).
Its convenience API constructs finite-group resolutions; it also accepts
an explicitly supplied integral HAP resolution for an infinite group.
The supplied checkout contains finite-group benchmark outputs and universal
cochain formulas, but no all-230 affine-space-group stacking answer table.
This availability check was repeated over all 191 tracked files and every
locally available branch/tag: `main`, `origin/main` and `origin/HEAD` all
resolve to the same pinned commit. The checkout is shallow; this statement
does not cover unpublished files or unfetched revisions. The reproducible

`runs/comparison_external/reference_inventory.json`, generated by
`scripts/inventory_reference_checkout.py`. README lines 337–343 mention

The documented native extension path additionally requires a finite group;
accepting a supplied infinite-group resolution at the API boundary does not

The four genuine extension disagreements are:

| SG | Historical draft transcription | Independently computed |
|---|---|---|
| 68 | Z2^3 + Z4 | Z2^5 |
| 81 | Z + Z2^4 + Z8^3 | Z + Z2^2 + Z4 + Z8^3 |
| 82 | Z + Z2^4 + Z8^2 | Z + Z2^2 + Z4 + Z8^2 |

Here `+` means direct sum. The four rows are from Table III, source page 6
of the historical transcription. A subsequent check against the separately
supplied `tables_classification.tex` confirms all four values (lines 18, 31,
32 and 51). They are therefore legacy computational claims, rather than
unconfirmed transcription discrepancies. The manuscript attributes its
Extension column to existing GAP SptSet results, with additional input for
nonzero p+ip. No row-level old derivation was supplied that diagnoses the
cause; see `HISTORICAL_STACKING_REVIEW.md` and the preserved source hashes.
The original completed SptSet logs also contain all four same results with
exit code zero. Their read-only copies and original-path hashes are in
`reference/legacy_stacking_context/`; parsed evidence is in
`results/boss_layers/historical_log_evidence.json`. These strengthen the
provenance of the old claims, without providing their missing cochain-level
relation derivations.

For SG68 and SG101 the independent calculation has one Majorana generator,
no CF generators and no surviving p+ip layer. Its actual measured relation
is `2B1=0`; the bosonic groups are Z2^4 and Z2^2 respectively. These results
use the full cochain engine, not the native pure-CF shortcut.
For example, the saved SG68 reduction uses incoming CF coordinates
`[1,1,1,0]` and incoming bosonic coordinates `[1,0,1,-1,0,-1,1,0]`;
SG101 uses `[0,0,1]` and `[0,0,1,0,0,1,0]`. Those coordinates identify
the checked lower gauge relations that trivialize the doubled MC state.
They locate the disagreement in relation reduction without presuming which
step of the historical derivation or transcription was responsible.

For SG82 one saved marked lower presentation has bosonic D1,D2 of order4,
CF generators C1,...,C4 of quotient order2, and Majorana B1 of quotient
order2, with

```
2C1=2C2=0,  2C3=3D1,  2C4=3D2,  2B1=D2,  2P1=C1.
```

These correlated relations give the displayed full group. Generator names
and coefficient vectors are tied to the saved Smith basis; they should not
be compared across different backend versions without a change of basis.
Targeted full-cochain and alternative-lift audits are recorded separately
below as they complete. No computed result is adjusted to fit the draft.

The lower stacking groups for SG81 and SG82 are respectively
`Z2^3 + Z8^3` and `Z2^3 + Z8^2`. The historical totals add a split Z2.
The actual relation `2P1=C1`, with C1 independent of every other higher
relation and of order2, replaces that pair of Z2 factors by a Z4 factor.

There is an independent geometric consistency check for these two rows.
The exact affine groups admit a projection onto their cyclic order-four
rotoinversion point group and an order-four section. The actual projection
composed with the section is checked on all four point-group elements.
Naturality therefore requires the point-group classification to be a direct
summand. An independent full calculation on finite C4, with odd generator
acting by orientation and omega=0, gives Z4 and the relation `2P=C`.
The supplied current point-group table agrees. The historical SG81/82
totals have only order2 and order8 primary cyclic factors, so they cannot
contain Z4 as a direct summand. The independently computed totals satisfy
this restriction. This is a direct-summand argument, not a substitution of
a finite point group for an infinite space group. Exact matrices and the
finite calculation are retained in `runs/finite_c4_retraction_controls.json`;
reproduction is `tests/compute_c4_retraction_controls.g`.

# 3+1D Spin-1/2: historical source differences

These are historical comparisons against the retained CI model without independent E8 decoration, not new calculation results. Each R3 version has its own column.

**✓** means the same reported group; **×** means a different reported group. For improper groups, the source entry is the explicitly named independent-E8 quotient; this does not establish a physical root map.

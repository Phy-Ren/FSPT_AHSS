# 3+1D Spinless: historical source differences

These are historical comparisons against the retained CI model without independent E8 decoration, not new calculation results. Each R3 version has its own column.

**✓** means the same reported group; **×** means a different reported group. For improper groups, the source entry is the explicitly named independent-E8 quotient; this does not establish a physical root map.

| Case | Old retained model | R3 arXiv v2 | R3 journal 2025 | E8 scope |
| --- | --- | --- | --- | --- |

| `point3_14_spinless` (D2d) | Z2^3 | **×** Z2^2 x Z4 | **×** Z2^2 x Z4 | Named neutral E8 quotient |
| `point3_17_spinless` (C3i) | Z8 | **×** Z2 x Z4 | **×** Z2 x Z4 | Named neutral E8 quotient |
| `point3_20_spinless` (D3d) | Z4 x Z8 | **×** Z2 x Z4 | **×** Z2 x Z4 | Named neutral E8 quotient |
| `point3_26_spinless` (D3h) | Z2^3 | **×** Z2^4 | **✓** Z2^3 | Named neutral E8 quotient |
| `point3_32_spinless` (Oh) | Z2^4 x Z4 | **×** Z2^3 x Z4 | **×** Z2^3 x Z4 | Named neutral E8 quotient |

R3 denotes Jian-Hao Zhang, Shang-Qiang Ning, Yang Qi, and Zheng-Cheng Gu: [arXiv:2204.13558v2](https://arxiv.org/abs/2204.13558v2) and [Physical Review X 15, 031029 (2025)](https://doi.org/10.1103/PhysRevX.15.031029). Both use interacting real-space topological crystals. No free-fermion classification is used in these columns.

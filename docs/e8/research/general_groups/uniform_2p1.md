# 2+1D: uniform responses and an abstract splitting

The ordered fields are `(e_0,n_0,n_2,nu_3)`. This is an algebraic argument
about completed stacking groups, not a new global classification table.

If `s` is nontrivial, both uniform integer coordinates vanish. For trivial
`s`, let the allowed completed CI response image be `A=mZ`, possibly zero.
The exact sequence `0 -> K -> E -> A -> 0` of abelian stacking groups
splits when `A` is nonzero: choose a completed lift `X` of `m` and send
`km` to `kX`. If `A=0`, the group is simply `K`. A symmetric neutral E8
layer adds the independent free response direction `e_0`, so the response
quotient is again free and the same splitting argument applies.

Thus an unknown microscopic nonzero-`n_0` product-coordinate map need not
create an abstract-group ambiguity **once** the physical kernel, actual
allowed response image, and completed lifts are known. The argument
neither supplies those physical identifications nor determines the integer
`m`. Different choices of lift change coordinates on the split group.

Keep `e_0=0` separate from any E8-inclusive result file, and keep `n_0=0`
separate from all allowed `n_0`. A fixed nonzero-`n_0` fiber is not itself
a stacking group. No mixed or E8-inclusive classification table follows
from this argument alone.

\section{A local Cartan-polarization certificate}\label{app:derivations}
This is an auxiliary Cartan-polarization identity. It is not a second definition of a physical source or product. Let $z$ be a binary three-cocycle and $x,x'$ binary one-cocycles. A normalized binary four-cochain $J_z$ solves
\begin{align}
\dd J_z={}&\Delta\zeta_{3,1}(z,x)
+(zx)\cup_3(zx')+(\Sq^1z)(x\cup_1x')+zxx'.
\end{align}
On $01234$ put
\begin{equation}
(z_0,z_1,z_2,z_3)=(z_{0123},z_{0124},z_{0134},z_{0234}),
\quad x_a=x_{0a},\quad x'_b=x'_{0b}.
\end{equation}
Then $J_z=\sum z_i z_j x_a x'_b$, over the following 22 quadruples $(i,j,a,b)$:
\begin{center}\small
\begin{tabular}{llll}\toprule
$(0,0,1,1)$&$(0,0,1,3)$&$(0,0,3,1)$&$(0,0,3,4)$\\
$(0,0,4,3)$&$(0,1,1,3)$&$(0,1,3,1)$&$(0,2,1,3)$\\
$(0,2,1,4)$&$(0,2,3,1)$&$(0,2,4,1)$&$(0,3,1,3)$\\
$(0,3,3,1)$&$(1,1,1,1)$&$(1,2,1,4)$&$(1,2,4,1)$\\
$(2,2,1,1)$&$(2,2,1,4)$&$(2,2,4,1)$&$(2,3,1,4)$\\
$(2,3,4,1)$&$(3,3,1,1)$&&\\\bottomrule
\end{tabular}
\end{center}
The symbolic calculation solves the identity as a polynomial in independent simplex cocycle variables and imposes all degeneracies. There are 160 candidate monomials and the normalized system has rank 151. The selected 22-term answer is completely specified; the remaining kernel is a normalization freedom, not evidence that all choices define the same physical product.

# 3D point groups: retained-model comparisons

The computed column contains the retained CI, charge and group-cohomological phase model. Each real-space source version has its own reference column. For improper groups those columns are explicitly source-side quotients by independently identified neutral E8 roots; equality of invariant factors is not a verified physical quotient map. No missing E8 operation is assigned zero.

Each row has one group and one physical spin. `0` is the trivial group. `N/A` means this source or quantity does not apply; `UNVERIFIED` means a relevant value or map has not been established; `NOT COMPUTED` means the runtime does not supply that object. An abstract match is not a physical generator-map or completeness certificate.

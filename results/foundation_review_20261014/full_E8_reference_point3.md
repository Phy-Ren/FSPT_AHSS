# 3D point groups: full physical reference groups

Reference-only table. Independent neutral E8 decorations are retained wherever the cited physical classification includes them. There is no computed full-E8 physical classification column. The values must not be compared directly with the retained-model column in another table without a sector map.

Each row has one group and one physical spin. `0` is the trivial group. `N/A` means this source or quantity does not apply; `UNVERIFIED` means a relevant value or map has not been established; `NOT COMPUTED` means the runtime does not supply that object. An abstract match is not a physical generator-map or completeness certificate.

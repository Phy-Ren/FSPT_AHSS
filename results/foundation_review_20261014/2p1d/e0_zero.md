# 2+1D current scope: e0=0

All current 2+1D result tables exclude the independent neutral E8 response.
The runtime does not implement E8 decoration. Within each physical spin,
`n0=0` and all allowed `n0` have separate directories and result files.

- [Spinless](spinless/README.md)
- [Spin-1/2](spin_half/README.md)

The [e0-inclusive scope](e0_included.md) is a separate, deferred file.

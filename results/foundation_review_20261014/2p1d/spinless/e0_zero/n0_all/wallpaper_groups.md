# 2+1D Spinless wallpaper groups: all allowed n0, e0=0

All allowed uniform CI coordinates are included together. This is the supplied no-independent-E8 model, not a computed full physical invertible-phase classification. A single fixed nonzero-n0 fiber is a torsor, not the group displayed here. For orientation-reversing cases the allowed n0 is only zero, so the relative reference applies. Where n0 varies, the physical product/response calibration remains unverified even when the reported groups agree.

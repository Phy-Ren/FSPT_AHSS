Choose one physical spin convention:

- [Spinless](spinless/README.md)
- [Spin-1/2](spin_half/README.md)

Each spin has separate `n0=0` and all-allowed-`n0` files. Point groups and
wallpaper groups also have separate tables. All current results fix
[e0=0](e0_zero.md). The [e0-inclusive scope](e0_included.md) is deferred
and contains no classification table.

# Current 2+1D results: e0=0

Every result file in this directory fixes the independent neutral E8
response to zero. The runtime does not implement E8 decoration.

Files beginning `n0_zero_` fix `n0=0`. Files beginning `n0_all_` allow all
admissible `n0` in the current product convention. These scopes never
share a classification table. Point and wallpaper groups are also
separate, and `_spinless` and `_spin_half` are different files.

Use the [table index](../README.md) to select a specific file. The
[e0-inclusive status](../e0_included/README.md) is separate and deferred.

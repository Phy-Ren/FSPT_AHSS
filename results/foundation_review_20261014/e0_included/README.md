# E0-inclusive and E8-decorated results: deferred

No classification table is supplied here. E8 decoration is not
implemented. This work is deferred at the user's request; complete
E8-inclusive tables will be produced separately after implementation and
review. A placeholder group or an appended factor is not a calculation.

Current 2+1D result tables fix [e0=0](../e0_zero/README.md). Their `n0=0`
and all-allowed-`n0` sectors, and their two physical spin conventions,
have separate files listed in the [table index](../README.md).

The earlier full reference-only tables are withdrawn from the active set
and preserved in Git history at `f918528`. Raw source fixtures remain
available for future work. The [E8 extension notes](../../../docs/foundations/e8_extension.md)
record the pending mathematical input; they are not implemented results.

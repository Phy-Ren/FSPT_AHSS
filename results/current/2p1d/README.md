# 2+1D insulator examples

All **10 planar point groups and 17 wallpaper groups** are computed for each physical spin: 54 backgrounds and 108 response-sector entries. The uniform E8 response is **`e0=0`** throughout this collection. The `n0=0` sector and all allowed uniform IQH responses have separate tables.

## Spinless

- [n0=0: point groups and wallpaper groups](spinless/n0_zero/README.md).
- [All allowed n0: point groups and wallpaper groups](spinless/n0_all/README.md).

## Spin-1/2

- [n0=0: point groups and wallpaper groups](spin_half/n0_zero/README.md).
- [All allowed n0: point groups and wallpaper groups](spin_half/n0_all/README.md).

Each table gives `(e0,n0,n2,nu3)` and the final stacking group, with separate versioned interacting-reference columns. The zero-IQH sector is the kernel of the actual response homomorphism, including its stacking relations. Wallpaper calculations retain translations and glides.

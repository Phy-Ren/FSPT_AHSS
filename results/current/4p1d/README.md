# 4+1D internal insulator examples

This collection contains **18 exact symmetry backgrounds** and **32 response-sector entries**. Internal groups carry no crystalline spin labels.

- [14 commuting cyclic groups: zero intrinsic response](internal_cyclic/intrinsic_zero.md).
- [14 commuting cyclic groups: all intrinsic responses](internal_cyclic/intrinsic_all.md).
- [Unitary charge conjugation](charge_conjugation.md): the intrinsic row is symmetry-forbidden.
- [AI/AII: zero intrinsic response](time_reversal_intrinsic_zero.md).

Each computation retains the full `(e2,n2,n4,nu5)` products, joint gauges, incoming identifications and root relations. The cyclic physical comparison tests the entire relation lattice against independently constructed eta characters. The all-intrinsic cyclic table additionally uses the explicit symmetry-independent I,J section; this does not assert a general opened-intrinsic implementation.

References appear in separate columns with their exact symmetry and response scope. AI/AII full groups and embedded response lattices remain distinct from their computed zero-intrinsic kernels.

# Computed U(1)^f insulator examples

The current catalogue contains 124 distinct backgrounds and 178 response-sector entries. It includes all 54 planar/wallpaper backgrounds and all 64 spatial point-group backgrounds. Each 2+1D background has separate n0=0 and all-allowed-n0 tables, both with e0=0. The 3+1D tables include the computed neutral E8 section.

- [2+1D: point groups and wallpaper groups](2p1d/README.md).
- [3+1D: crystalline groups](3p1d/README.md).
- [4+1D: internal cyclic groups](4p1d/README.md), 6 completed inputs.

Each row gives the four final data layers, final stacking group, and separately cited interacting references. Physical spins and response sectors have separate files. **✓** marks the same reported group; **×** marks a different reported group.

# 3+1D insulator examples

All **32 crystallographic point groups** are computed for each physical spin. The space-group collection contains **460 completed backgrounds**, covering all **230 space groups for both spins**. Every entry includes the four data `(e1,n1,n3,nu4)`, E8 first, and the final stacking group.

## Spin-1/2

- [32 point groups](spin_half/point_groups.md) · [CSV](spin_half/point_groups.csv).
- [Space groups](spin_half/space_groups.md) · [CSV](spin_half/space_groups.csv).

Space groups use the full infinite affine group, retaining translations, weak phases, and nonsymmorphic operations. The neutral E8 section and CI, charge, and phase relations are assembled into the final integer presentation.

Point-group reference columns cite full interacting classifications. The space-group Song–Xiong–Huang comparison concerns **only the neutral E8 layer**; full interacting electronic references remain unverified. The computed four-data model's identification with the complete physical CI kernel remains conditional.

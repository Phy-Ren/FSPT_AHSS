# Both physical conventions: finite point groups

These are the **finite matrix point groups**, with no translation subgroup. `0` is the trivial group. The row index belongs to the new finite catalogue, not to the historical manuscript row numbering.

The crystalline spin-half column uses internal `omega=0, s=w1`; crystalline spinless uses internal `omega=w2+w1², s=w1`. A dagger marks an abstract full-group type determined over the entire allowed upper-extension fiber; no actual upper phase/marked square is claimed for that row.

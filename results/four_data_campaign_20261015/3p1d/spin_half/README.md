# 3+1D spin-1/2 point groups

- [With E8: selected four-data model](with_e8/point_groups.md).
- [Without E8: CI sector](without_e8/point_groups.md).

All 32 CI groups are unchanged by the fresh calculation. With E8, the 20
extracted Debray comparisons give 18 matches and two differences: D2 and D6
each compute Z2^2, while the reference prints Z2^3. Their neutral E8 groups
are zero, so adding E8 does not change either discrepancy. The remaining 12
comparisons are unverified.

The [independent grading audit](../../../../docs/foundations/debray_d2_grading_audit.md)
finds a source-internal grading issue relevant to these entries. This is our
audit, not a published erratum. The comparison tables preserve the printed
values and mark the differences explicitly.

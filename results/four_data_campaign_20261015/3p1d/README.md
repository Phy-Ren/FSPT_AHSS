# 3+1D point groups — fresh calculations

All 32 crystallographic point groups were rerun for each physical spin. All
64 CI runs completed and their final groups agree with the previous calculations.
Each new CI presentation was then extended using the selected neutral E8
section. Spin conventions and E8 sectors have separate tables.

- [Spinless](spinless/README.md).
- [Spin-1/2](spin_half/README.md).

The neutral group H1(G,Z_s) was computed from each finite group, with explicit
crossed cocycles and root-removal gauges: it is zero in the 22 proper-group
cases and Z2 in the 42 improper-group cases. The final groups follow from the
combined integer presentations. This calculation verifies the selected 3+1D
section; identifying its CI kernel with the complete physical classification
still requires a physical comparison of generators and relations.

Against the full interacting groups extracted from Debray v3, 37 of 40 checked
entries match and 3 differ; 24 entries remain unverified, not counted as matches.
The spin-specific pages identify those differences. The two mirror comparisons
with Ning–Mao–Li–Wang both match. Against Zhang–Ning–Qi–Gu, the arXiv v2 and
journal tables each give 51 matches and 13 differences, but the differing cases
are not identical between versions. Neither version is used as a classification
input. Each table records the exact citation and method.

The E8-excluded tables separately show the source's full group and, when the
source names a neutral E8 root, its documented quotient. The E8-inclusive
tables compare full groups directly. A matching group type alone does not
establish a physical root map.

# 2+1D diagnostic calculations — e0=0

The 44 new runs cover C2, C2v, C4, C4v, C6, C6v and wallpaper groups pg,
pgg, p4, p4g, p6m, for both physical spins and both n0 sectors. Every run fixes
e0=0. A future e0-inclusive calculation belongs in separate files.
Where n0 varies, the supplied product's complete physical response calibration
remains open even when a final group agrees with a reference.

- [Spinless](spinless/README.md).
- [Spin-1/2](spin_half/README.md).

All 44 final groups are unchanged. The 22 kernels of the all-n0 presentations
agree with the independently computed n0=0 groups; their integer presentations
also agree exactly. All 20 wallpaper presentations preserve filling.

The relative rotation groups remain C2: Z4, C4: Z2 x Z8, and C6: Z3 x Z12 for
each spin. For example, the completed C2 charge root satisfies 2x=b and 2b=0,
giving Z4. This nontrivial stacking extension is retained by the rerun.

All 12 selected relative planar point cases match the extracted Debray groups.
The Zhang–Yang–Qi–Gu arXiv and journal point tables give respectively 6/12 and
3/12 matches and remain separate reference columns. All 10 selected relative
wallpaper cases match each version's final stacking group; their final charge
and phase layers each match all 10 Wang–Qi–Fang–Cheng–Gu comparisons. Filling
normalization remains a distinct comparison requiring the source coordinate map.

These are diagnostic reruns, not a new exhaustive wallpaper campaign. The
[earlier full coverage](../../foundation_review_20261014/2p1d/README.md) remains
available separately.
